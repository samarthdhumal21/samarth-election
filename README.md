> **"Understand Your Vote. Shape Your Nation."**

ElectVerse is an educational web portal designed to demystify the Indian Electoral Process for the general public. Built with a sleek, modern UI inspired by Spotify, the platform offers an engaging, interactive, and visually stunning way to learn about the world's largest democratic exercise.

## ✨ Features
- **Modern UI/UX**: Dark mode with vibrant green accents, glassmorphism, smooth animations, and a sidebar navigation reminiscent of Spotify.
- **Interactive Timeline**: A step-by-step visual journey of the 8 stages of the Indian election process.
- **15-Question Quiz**: Test your knowledge with instant feedback, explanations, and a performance rating.
- **Searchable Glossary**: Over 35 essential election terms categorized (Technology, Officials, Voting Process, Legal Terms).
- **Data Infographics**: Visual charts depicting voter turnout trends, seat distributions, and registered voter growth using Chart.js.
- **Downloadable Resources**: Official ECI reference documents on EVMs, the election timeline, and the Election Commission.
- **Fully Responsive**: Optimized for all devices from mobile to desktop.
- **Accessibility**: Keyboard navigation and descriptive text support.

## 🛠️ Tech Stack
- **Backend**: Python (Flask)
- **Frontend**: HTML5, Vanilla CSS3, JavaScript (Vanilla)
- **Visuals/Icons**: Font Awesome, Chart.js

## 💻 How to Run Locally

Since this project was adapted to use a Python backend instead of Node.js/Vite, please follow these instructions:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/election-process-education.git
   cd election-process-education
   ```

2. **Install requirements:**
   Make sure you have Python installed, then install Flask:
   ```bash
   pip install flask
   ```

3. **Run the local server:**
   ```bash
   python app.py
   ```

4. **Access the application:**
   Open your browser and navigate to `http://127.0.0.1:5000/`.
